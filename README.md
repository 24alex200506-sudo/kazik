# Nekit Games: Telegram Mini App

Что внутри
- `public/index.html` — сайт: экран выбора игры по центру, кнопка «Кошелёк», пополнение через Crypto Bot.
- `server.js` — сервер (Node 18+, без зависимостей): проверка Telegram-пользователя, баланс в USDT, счета Crypto Pay, вебхук.

## Запуск
1. `cp .env.example .env` и заполните:
   - `BOT_TOKEN` — токен бота от @BotFather.
   - `CRYPTO_PAY_TOKEN` — в @CryptoBot: Crypto Pay → Create App → API Token.
     Для теста: @CryptoTestnetBot и `CRYPTO_PAY_API=https://testnet-pay.crypt.bot/api`.
   - `BOT_LINK` — ссылка на вашего бота (кнопка возврата после оплаты).
2. `npm start` (откроется на порту 3000).
3. Нужен публичный HTTPS-адрес (VPS + nginx, Render/Railway, для проверки — cloudflared или ngrok).
4. @BotFather → `/newapp` (или Bot Settings → Menu Button) → укажите адрес сайта.
5. @CryptoBot → Crypto Pay → My Apps → ваше приложение → Webhooks → включить →
   `https://ВАШ-ДОМЕН/api/crypto-webhook`.
   Без вебхука баланс всё равно пополнится: сайт сам проверяет счёт каждые 4 секунды и при каждом открытии кошелька.

## Проверка без Telegram
`DEV=1 npm start` и откройте http://localhost:3000. Платежи пойдут на тестовую сеть, если указан testnet-токен.
На боевом сервере `DEV` должен быть 0.

## Важно
- Токены только в `.env`, не в `index.html` и не в git. Токен, который попал в переписку, перевыпустите (@BotFather → /revoke; в Crypto Pay → Revoke token).
- Сейчас реальный баланс (USDT) только пополняется. Игры работают на демо-балансе: результаты считаются в браузере, их легко подменить, поэтому на реальные деньги их подключать нельзя. Следующий шаг: перенести расчёт игр на сервер, затем вывод средств.
- Приём реальных денег в азартных играх требует лицензии и ограничений по возрасту/странам. Это нужно решить до запуска для игроков.

## Стикеры на кнопках игр
Номера: 1 Crash, 2 Tower, 3 Mines, 4 Plinko, 5 Бонусы, 6 Nuts.

Способ 1 (автоматически): скопируйте `stickers.json.example` в `stickers.json`, впишите имя набора
(из ссылки `t.me/addstickers/ИМЯ`) и эмодзи стикера в нём или его номер `index` (с нуля). При запуске сервер сам
скачает стикеры через бота в `public/stickers/`. Бот должен быть из .env (`BOT_TOKEN`).

Способ 2 (вручную): положите файлы в `public/stickers/` с именами `g1.tgs`, `g2.tgs`... (подходят `.tgs`, `.webm`, `.webp`).

Если стикера нет, на кнопке остаётся обычное эмодзи.

## Анимированные эмодзи по умолчанию
Если своих стикеров нет, кнопки показывают анимированные эмодзи Google Noto (лицензия CC BY 4.0, источник: fonts.gstatic.com).
Для некоторых эмодзи (например 🏗️, 🌰) анимации может не быть: тогда показывается обычное эмодзи. Лучше поставить свои стикеры способами выше.
